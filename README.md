# 지구 3D 모델 — WebGL

## 실행

`index.html`을 Chrome 또는 Edge로 연다. 파일을 다운로드했다면 폴더 구조를 유지한다.
외부 라이브러리와 설치 과정 없이 동작하며, 이미 저장된 고도 데이터로 오프라인 실행이 가능하다.
IntelliJ의 Java 실행 버튼은 사용하지 않는다.

## 파일

- `index.html`: 화면, 슬라이더, 체크박스
- `style.css`: 화면 배치
- `earth.js`: 행렬 계산, 구 생성, 셰이더, 입력 처리, 회전
- `data/elevation.js`: 브라우저에서 사용하는 고도 자료
- `data/elevation.json`: 같은 자료를 JSON으로 저장한 원본 격자
- `download_elevation.py`: 공개 API에서 고도 자료를 받는 Python 프로그램

## 구현 내용

1. 위경도로 구를 만들고 인접한 정점들을 삼각형으로 연결한다.
2. 실제 고도를 양선형 보간해 정점 반지름을 변경한다.
   `r = 1 + max(elevation, 0) * exaggeration / 6371000`
3. 단편 셰이더에서 인접 고도를 읽어 동서/남북 방향의 기울기를 구한다.
   기울기에 따라 법선을 바꾸는 것이 범프 매핑이다.
4. 변형된 지형과 범프 효과에 같은 고도를 사용한다. 두 기울기를 중복해서 더하지 않고
   범프 사용 시 최종 음영 배율을 `max(고도 배율, 범프 배율)`로 정한다.
5. 지구의 모델 행렬은 `축 기울기 * Y축 자전`이다. 기본 기울기는 23.4도이다.
6. 광원 방향은 월드 공간에 고정된다. 지구가 회전하면 지표의 낮과 밤이 달라진다.
7. 자전축은 주황색 선, 적도는 청록색 선으로 표시한다.

## 조작

- 드래그: 관찰 방향 변경, 휠: 확대/축소
- 캔버스에 초점을 맞춘 뒤 방향키: 관찰 방향, + / -: 확대/축소
- 자전 일시정지 → 광원 방향만 이동하면 범프 음영을 비교하기 쉽다.
- 고도 변형 끄기 + 범프 켜기: 외곽선은 구, 음영만 지형처럼 보인다.
- 두 효과 모두 끄기: 매끄러운 구에 고도 색상만 표시된다.
- 고도 변형 켜기 + 범프 끄기: 정점 변형 및 그 표면의 법선으로 표시된다.
- 초기화: 배율, 시점, 광원, 회전 상태를 기본값으로 복원한다.

## 데이터 출처와 한계

- 제공 API: https://api.opentopodata.org/v1/etopo1
- 설명: https://www.opentopodata.org/datasets/etopo1/
- 원 자료: NOAA ETOPO1 (육지 고도와 해저 지형).
- 수집: 2026-11-22 UTC. 실제 시각은 JSON의 retrievedUTC를 확인한다.
- 전 지구 위경도 **2도 간격, 180 × 91 = 16,380개** 표본이다.
  ETOPO1 원자료의 상세 해상도를 모두 받은 것이 아니다. 적도에서 2도는 약 222 km이다.
- 극점은 경도마다 같은 위치이므로 극점 행의 평균값을 사용한다.
- 색상은 위성사진이 아니라 고도 구분용이다. 초록색은 식생, 흰색은 실제 눈의 관측을 뜻하지 않는다.
- 바다는 반지름 1의 해수면으로 표현하고 해저 고도는 바다 색상 구분에만 사용한다.
- 고도 35배, 범프 음영 80배가 기본값이다. 실제 지형을 과장한 시각화이다.
- 작은 섬, 작은 산, 자세한 해안선은 생략된다. 보간이나 메시 세분화가 실제 자료 해상도를 높이지는 않는다.
- 범프 매핑만으로는 실루엣이 변하지 않는다. 실루엣 변경은 정점 변형 기능이다.
- 광원은 방향광이고, 공전/계절/달/대기/그림자 투영은 구현하지 않았다.
- 자전 속도는 관찰용 각속도이며 실제 시간과 일치하지 않는다.

## 데이터 다시 받기 (선택)

Python 3가 설치된 경우 이 폴더에서 `python download_elevation.py --step 2`를 실행한다.
인터넷이 필요하다. 공개 API의 100개 위치/요청, 초당 1회 제한을 지키며 중간 결과를 저장한다.
기존 파일만으로 실행할 수 있으므로 다시 받을 필요는 없다.
1도 간격은 요청 수가 많으므로 제한과 소요 시간을 확인한 후 사용한다.

## 확인한 항목

Chrome의 자동 브라우저 테스트로 셰이더 컴파일, WebGL 오류 없음,
정점 변형/범프 효과의 화면 차이, 광원/축 변경, 일시정지/재생/초기화,
경도 경계와 극점 고도 일치, 모바일 너비의 가로 넘침 없음을 확인했다.
고도 자료 정확도 자체를 현장 측량으로 검증한 것은 아니다.

## 수업과 연결

- 08-lighting.pdf: 법선과 광원 방향으로 계산하는 조명

## AI 활용 기록

고도 API의 응답 처리와 범프 매핑의 법선 계산을 이해하는 데 어려움이 있어 AI의 코드 예시와 설명을 참고하였다. 구체적으로 위도·경도별 고도 값을 요청하고 응답을 확인하여 저장하는 과정, 주변 고도의 차이를 이용해 표면의 기울기와 법선을 계산하는 과정에서 도움을 받았다. 또한 고도 값을 텍스처의 두 색상 채널에 나누어 저장하고 셰이더에서 복원하는 방법을 참고하였다.
